# Мобильное приложение для авторизации на базе Retrofit

## Описание

Это простое мобильное приложение, реализующее функционал авторизации, регистрации и выхода из аккаунта с использованием библиотеки Retrofit для работы с сетевой частью. Приложение также предоставляет возможность просмотра списка зарегистрированных пользователей, доступный только для авторизованных пользователей. Для хранения токена между сессиями работы приложения используется DataStore.

## Функции

- **Авторизация:** Возможность входа в приложение с использованием зарегистрированных учетных данных.
- **Регистрация:** Пользователи могут создавать новые учетные записи.
- **Выход из аккаунта:** Пользователи могут выйти из своего аккаунта.
- **Просмотр пользователей:** Доступный список зарегистрированных пользователей для авторизованных пользователей.

## Технологии

- **Язык программирования:** Kotlin
- **Библиотеки:** 
  - Retrofit (для работы с сетевой частью)
  - OkHttp (перехватчик для обработки запросов)
  - DataStore (для хранения токена)
- **Платформа:** Android
- **UI Toolkit:** Jetpack Compose
